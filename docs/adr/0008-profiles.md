# ADR 0008: 프로파일: gpu-12g는 Qwen3-1.7B(데모), rtx4090-24g는 Qwen3-8B

## 상태
채택. 24GB 프로파일은 **적재해 본 적이 없다(추정)**.

## 맥락
엔진 값(최대 길이, 메모리 비율, 동시 시퀀스, LoRA 순위)은 GPU에 따라 다르고 코드에 박으면 안 된다(공통 규칙 D47). 학습된 어댑터는 기반 모델에 묶인다.

## 결정
설정 프로파일 파일로 둔다. `gpu-12g`: Qwen3-1.7B, bf16, `max_model_len` 4096, 메모리 비율 0.8, `max_num_seqs` 4 — 파이프라인 데모용이며 학습된 4B/8B 어댑터는 올리지 않는다. `rtx4090-24g`: Qwen3-8B, `max_model_len` 8192, 0.9, `max_num_seqs` 8 — 학습된 어댑터의 서빙 목표.

## 왜 (따른 표준과 근거)
사용자 지시와 D81(gpu-dev 12GB에 Qwen3-4B는 못 올린다, 가벼운 Qwen3 계열이면 `prompt-4`와 채팅 템플릿 `enable_thinking=False`가 그대로 맞는다), D74(24GB급은 8B 이상). `gpu-12g`의 값은 2026-10-27 gpu-dev 1회 측정(적재 약 10.1GB, KV 5.42GiB/50,720토큰)이다. `rtx4090-24g`의 값은 **측정이 아니라 계산한 추정**이고 모델 카드 수치를 기억에 의존한 것이라 미확인이라고 프로파일 주석이 스스로 적고 있다. 14B는 bf16으로 24GB에 들어가지 않아 쓰지 않는다.

## 검토한 대안과 버리는 이유
- 12GB에 4B: 못 올린다(사용자 지시). 
- 하나의 범용 프로파일: GPU 크기별 값이 달라 불가.
- 양자화 등 다른 프로파일: 미정.

## 결과
얻는 것: 환경 차이를 설정으로 격리. 감수하는 것: 12GB 프로파일의 성능은 판단 근거가 아니다. 입력 길이 상한(ADR 0012)은 `max_model_len` 4096에 맞춘다.

## 되돌리는 조건
24GB 실측 후 프로파일 값과 `status`를 갱신한다. 기반 모델이 바뀌면 어댑터를 새로 학습·패키징해야 한다.
