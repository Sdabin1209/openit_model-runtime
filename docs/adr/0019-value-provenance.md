# ADR 0019: 근거 없는 값의 출처 분류와 측정 계획 (값은 바꾸지 않는다)

## 상태
채택(2026-10-29, 표준성 점검 `docs/audit/standards-2026-10-29.md`의 N-/? 항목에 대한 D89 조치). 이 ADR은 값을 바꾸지 않고 출처를 기록한다. 아래 모든 값은 **측정하지 않았다**(예외는 표에 따로 적었다). 측정하지 않은 값의 시험 통과 수치를 이 문서에 적지 않는다.

## 맥락
점검에서 다음 값들이 "초기값", "승인", "지시" 말고는 이유가 없다고 나왔다. 사용자가 값을 물으면 측정·표준·제약 중 무엇에서 나왔는지 답할 수 있어야 한다(D89). 이 ADR은 ADR 0003, 0006, 0007, 0012, 0016의 해당 문장을 한 곳에 모아 분류하고, 측정 계획을 붙인다.

## 결정
값은 그대로 둔다. 출처 분류는 다음 세 가지로만 쓴다. **측정** = 이 시스템에서 잰 값. **표준** = 이름 있는 표준·문서화된 관행. **제약** = 다른 값이나 계약에서 따라 나오는 부등식·일치 조건. 어느 것도 아니면 "초기값(출처 없음)"이라고 쓴다.

## 왜
측정하지 않은 값을 측정한 것처럼, 또는 표준에서 나온 것처럼 쓰지 않기 위해서다. 값을 지금 바꾸지 않는 이유는 바꿀 근거(측정)가 아직 없기 때문이다. 측정 없이 숫자를 바꾸면 또 하나의 초기값이 생길 뿐이다.

## 검토한 대안과 버리는 이유
- 근거가 없는 값을 지금 다른 값으로 바꾸기: 바꿀 근거가 없다. 기각.
- 값을 설정으로 열어 두기: 이미 환경 변수로 바꿀 수 있다. 문제는 값의 출처이므로 기록으로 해결한다.

## 결과
얻는 것: 값마다 출처 분류와 측정 계획이 한 곳에 있다. 감수하는 것: 값 자체는 여전히 초기값이다. 측정 전에는 이 값들의 적절성을 판단할 수 없다.

## 되돌리는 조건
H1·H4 실측 후 각 값을 측정값으로 바꾸고 이 ADR을 새 ADR로 대체(`Supersedes`)한다. 시간 예산(한 환자 턴이 모델을 두 번 부르는 문제)은 계약 변경이 필요해 이 ADR의 범위가 아니다. 호출별 예산 배분은 계약에서 정해지면 이 영역이 따른다.
